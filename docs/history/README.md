# Design history

The docs one level up describe the ROM as it is now. This folder keeps how it
got there: earlier layouts, phase plans, rejected options and bugs found on
the way. Read it to learn why something is the way it is. Don't rely on it for
current addresses or behaviour, because nothing here is updated when the code
changes.
